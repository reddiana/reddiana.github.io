# 예측가능성 선호
- ==계획==대로 ==정확==히 실행하는 것 선호
- 다소 도전적인 목표 수립 + ==정해진== 일정에 ==목표한== 실적 (이라고 쓰고 10% 정도 초과) 달성 선호
- 서프라이즈 싫어함
- 큰 초과 달성 별로 좋아하지 않음
	- 목표를 방어적으로 수립했다고 간주
	- 요행의 개연성을 배제하지 않음 → 지속가능성에 대한 별도 평가가 필요하다고 생각함
# 지속가능성 / 시스템화 선호
- 실적이 좋더라도
	- 내년에도 또 이만큼 할 수 있어? ← ==지속가능성==
	- 너 말고 다른 사람이 해도 이만큼 할 수 있어? ← ==시스템화==

# Top Down 문화
- Bottom Up이 허용되지 않는 문화
- 패스트 팔로우어 정책 시 유리
- 우수한 리더 부재는 곧 재앙
